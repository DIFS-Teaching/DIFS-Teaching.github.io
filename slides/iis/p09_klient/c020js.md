# JavaScript

- Původně jazyk pro jednoduché skripty na klientské straně (Netscape Navigator, 1995)
- Standardizován jako **ECMAScript** (ECMA-262)
  - Od ES2015 (ES6) výrazné rozšíření jazyka: moduly, třídy, `let`/`const`, `Promise`, později `async`/`await`
  - Nová verze standardu každý rok
- Postupně vznik rozsáhlejších programů
  - Tlak na rychlost zpracování
- Výkonné JS enginy: V8 (Chrome, Edge), SpiderMonkey (Firefox), JavaScriptCore (Safari)
  - Umožnily tvorbu rozsáhlých aplikací

---

# JavaScript jako platforma

- **Klientský JavaScript**
  - Aplikace běží ve webovém prohlížeči
  - Prohlížeč poskytuje API
    - DOM, `window`, `fetch()`, atd.
- **Serverový JavaScript**
  - „Osamostatněný“ JavaScript pro tvorbu obecných aplikací
  - Stejný jazyk, jiná API, řada dostupných knihoven (správce balíčků `npm`)
  - Nejčastěji [Node.js](https://nodejs.org/), novější alternativy _Deno_ a _Bun_
- _TypeScript_ – JavaScript se statickými typy
  - Dnes de facto standard pro větší projekty

# Klientský JavaScript

- Skripty vložené nebo odkazované z HTML kódu
  - Nativní podpora modulů: `<script type="module">`, `import` / `export`
- Lokální sestavovací nástroje (např. _Vite_, _esbuild_)
  - Běží opět na `Node.js`
  - Umožňují využít knihovny z `npm`
  - Překlad TypeScriptu, JSX apod. do JavaScriptu
  - Provede _sestavení_ do výsledného skriptu (_bundle_), optimalizace (minifikace, odstranění nepoužitého kódu)
